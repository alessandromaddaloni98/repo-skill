Before downloading the skill

This is the official skill to prepare an asset for sharing on repo-skill. The zip holds the same skill in two formats: one for Codex, one for Claude Code.

  1. Click Download now: you get repo-skill-publish.zip, containing one folder per agent and a README.txt.
  2. Copy the folder of the agent you use into the project holding the asset you want to share, at the path shown:
    • codex/ → .agents/repo-skill-publish/
    • claude-code/ → .claude/skills/repo-skill-publish/
    These are hidden folders (they start with a dot): in Finder show them with ⌘ ⇧ .. If they do not exist, create them.
  3. To create and publish the asset, write your agent a prompt like:

use the repo-skill-publish skill to prepare and publish the asset "<asset name>", contained in the files <file_name>
